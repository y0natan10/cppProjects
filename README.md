# cppProjects

A collection of C++ projects for automation, utilities, and learning.

## Projects

### Menu
A launcher utility to easily run and manage your other projects.  
Pin this executable to your taskbar and select which project to launch from a menu.  
You can add or remove projects from the menu for quick access.

### KarutaJobBoard
A scripting bot to automate repetitive commands for the Karuta Discord bot.  
It generates and types out the optimal set of commands for job board management, reducing manual effort.

### ResinCalculator
A tool to track progress and estimate time remaining for game projects that use a "resin" or energy system.  
It records entries, calculates total resin needed, and provides time breakdowns.

### TimeCalculator
A utility to add or manipulate time values (days, hours, minutes, seconds).  
Useful for figuring out future times or durations, and for practicing C++ class and operator overloading concepts.

### GuitarTrainer
A C++ application to help guitar players learn and practice chords.  
Displays chord diagrams, shows note locations on the fretboard, and processes chord progressions.
